# HR Interview Simulator

## Project Description
This project is an AI-powered HR Interview Simulator developed using Streamlit and OpenRouter API.

It helps students practice HR interview questions and receive AI-generated feedback.

## Features
- HR interview questions
- AI answer evaluation
- Score and feedback generation
- Answer history dashboard
- Streamlit UI

## Technologies Used
- Python
- Streamlit
- OpenRouter API
- Requests

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run the project

streamlit run app.py
